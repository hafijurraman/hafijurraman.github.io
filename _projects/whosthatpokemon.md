A Pokemon GO-inspired web application built on the MERN stack (MongoDB, Express, React, Node.js), integrating the Pokemon API to let users guess Pokemon names from images.

The app engaged more than 200 players, demonstrating its impact within the community.

**Tech:** React, Node.js, Express, MongoDB, Pokemon API.
