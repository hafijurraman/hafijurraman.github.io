An agent system that takes voice or text commands such as "Order me a cheeseburger" and automatically finds the nearest restaurant to start the order.

The core is a reliable scripted pipeline that extracts structured order details from an LLM and uses Python automation to navigate sites like McDonald's, ensuring 100% order accuracy. The deployment is architected with Docker and NGINX, hosted on a high-performance A100 GPU server and secured with SSL for encrypted browser access.

**Tech:** Python, LLMs, Docker, NGINX, browser automation.
