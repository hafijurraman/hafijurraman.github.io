A Node.js server implementing the Model Context Protocol (MCP) to provide AI applications with direct access to Google Calendar data.

It enables AI agents to fetch calendar events by date and return formatted meeting information through a standardized interface, making calendar context available to any MCP-compatible assistant.

**Tech:** Node.js, Model Context Protocol, Google Calendar API.
